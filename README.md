## Запуск

Откройте `index.html` в современном браузере. Установка, сборка и сервер не нужны. Вся разметка, стили и код находятся в одном файле. Внешних библиотек и сетевых запросов нет.

## GitHub Pages

1. Создайте репозиторий на GitHub.
2. Через Add file → Upload files загрузите `index.html`, `README.md` и `.nojekyll` в корень репозитория. ZIP предварительно распакуйте.
3. Откройте Settings → Pages.
4. В Source выберите Deploy from a branch.
5. Выберите ветку main и папку /(root), сохраните.
6. После завершения публикации GitHub покажет ссылку на сайт.

## Что работает

1. Фильтры продукта, конфигурации и активной рекламы меняют карточки, графики, историю и список.
2. Период меняет график и историю. Карточки показывают последнее состояние.
3. Поиск фильтрует только список страниц.
4. Нажатие на адрес или интервал истории открывает карточку страницы с текущими результатами по всем конфигурациям.
5. Решение по рекламе сохраняется в localStorage текущего браузера. Реальные кампании не изменяются.
6. Диалоги закрываются кнопкой или Escape.
