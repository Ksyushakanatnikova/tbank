## Что работает

1. Фильтры продукта, конфигурации и активной рекламы меняют карточки, графики, историю и список.
2. Период меняет график и историю. Карточки показывают последнее состояние.
3. Поиск фильтрует только список страниц.
4. Нажатие на адрес или интервал истории открывает карточку страницы с текущими результатами по всем конфигурациям.
5. Решение по рекламе сохраняется в localStorage текущего браузера. Реальные кампании не изменяются.
6. Диалоги закрываются кнопкой или Escape.
